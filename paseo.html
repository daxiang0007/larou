paseo 是什么

开源、自托管的编码 agent 编排与调度工具 — 桌面 / 移动端 / CLI / Web 统一管理多个 coding agent

01

核心定位

它不是某一个模型或 agent 本身，而是一层"控制面"——把多种 coding agent 统一接管起来，跑在你自己的机器上。

🔒

自托管 / 数据自有

守护进程（Node.js）跑在本地机器上，代码、密钥、执行环境都在你自己的环境里，不经第三方托管。

🖥️

Client-Server 架构

本地 daemon 管理所有 agent 进程；CLI / 桌面 / 移动 / Web 可同时连接，agent 断开客户端后仍在后台继续跑。

🔌

多 Provider，不锁死

内置 Claude Code、Codex、GitHub Copilot、OpenCode、Pi，以及 ACP 协议第三方 provider，也可接自定义 provider。

📱

跨设备接续

电脑上起的任务，可以从手机 App 继续看进度、继续对话，不依赖单一终端窗口。

02

能用它做什么

分屏并行跑多个 agent 给 agent 挂终端一起用 语音模式免打字 cron 定时自动触发任务 agent 互相调用（委员会/顾问模式） worktree 隔离并行改动

典型场景：让一个 agent 按固定节奏（比如每 30 分钟）巡检代码库、跑测试、续写重构，出结果时给你留言，不需要你手动开一个新会话去盯着。

03

基础 CLI 命令

paseo run启动一个新 agent 执行任务
paseo ls列出正在运行的 agent
paseo attach <id>实时流式查看某个 agent 的输出
paseo send <id>给运行中的 agent 追加新指令
paseo logs <id>查看该 agent 的完整时间轴日志
paseo stop <id>停止指定 agent
04

定时调度 · Schedule

这是"agent 调度"的核心：简单节奏预设（如 --every 30m）会自动编译成标准 cron 表达式，也可以直接写 cron 语法。

zsh — paseo schedule
# 每 30 分钟在指定目录跑一次 agent，完成后留一条笔记
paseo schedule create --every 30m --cwd ~/dev/my-app "Continue the refactor and leave a note."

# 查看所有已建立的调度
paseo schedule ls

# 暂停某个调度（不删除，可再启用）
paseo schedule pause <id>
05

项目 / 工作区 / 权限管理

项目paseo project create / ls / rename / delete
工作区paseo workspace create / ls / rename / archive
终端paseo terminal create / ls / send-keys / capture / kill
插件paseo plugin add / install / ls / update / remove
权限paseo permit ls / allow / deny
守护进程paseo daemon start / status / reload / stop

全局可选参数：--host（连接远程 daemon）、--json、-q/--quiet、--no-color。
